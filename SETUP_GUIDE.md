## 📝 Cara Menggunakan

### Enkripsi Teks Dasar

1. Pilih tab **"Enkripsi/Dekripsi"**
2. Pilih cipher dari dropdown
3. Masukkan kunci
4. Masukkan plaintext
5. Klik **"Encrypt"**
6. Copy atau download hasil

### Gunakan AES/RSA

1. Pilih tab **"Enkripsi/Dekripsi"** → **"Modern (AES/RSA)"**
2. Pilih algoritma
3. Klik **"Generate Key"** atau masukkan key manual
4. Masukkan plaintext
5. Klik **"Encrypt (Modern)"**

### Visualisasi

1. Buka tab **"Visualisasi"**
2. Pilih algoritma (Vigenere/Playfair)
3. Masukkan plaintext dan key
4. Lihat step-by-step visualization

### Analysis & Frequency

1. Buka tab **"Analisis Keamanan"**
2. Paste ciphertext
3. Klik **"Analisis"**
4. Lihat frequency chart, entropy, dan strength

---

## 🔑 Key Generator

### Generate Random Key

1. Buka tab **"Key Generator"**
2. Set panjang key (8-256 karakter)
3. Pilih tipe (Alphanumeric, Numeric, Hex, Binary)
4. Klik **"Generate Key"**
5. Copy atau download

### Key Strength Indicator

Setiap key akan ditampilkan level kekuatannya:

- 🔴 **Weak** (0-30%) - Panjang kurang, characters limited
- 🟡 **Medium** (30-70%) - Cukup, tapi bisa ditingkatkan
- 🟢 **Strong** (70-100%) - Aman untuk enkripsi

## 📊 Benchmark

Bandingkan performa enkripsi berbagai algoritma:

1. Buka tab **"Benchmark"**
2. Masukkan teks & jumlah iterasi
3. Klik **"Jalankan Benchmark"**
4. Lihat grafik perbandingan (Ops/Sec)

**Note**: Hasil benchmark tergantung CPU system Anda

## 🆘 Troubleshooting

### Fitur tidak berfungsi

- **Solusi**: Refresh halaman (Ctrl+F5 atau Cmd+Shift+R)
- Buka Developer Tools (F12) dan check console untuk error messages

### Dark mode tidak simpan

- **Solusi**: Aktifkan localStorage di browser settings
- Pastikan cookies tidak di-disable

### Download tidak bekerja

- **Solusi**: Check browser security settings
- Pastikan popup blocker tidak menghalangi download

### "Paste your text here" placeholder tidak hilang

- **Solusi**: Clear browser cache (Ctrl+Shift+Delete)
- Atau gunakan private/incognito window
